# 서울 커피·베이커리 3년 성장 상권 분석과 1호점 출점 제안

사모펀드가 보유한 커피·베이커리 브랜드의 신규 출점 전략 케이스입니다. 서울 열린데이터광장 상권분석서비스 데이터로 3년 뒤 성장할 상권을 고르고, 1호점의 인테리어 컨셉, 메뉴, 손익을 설계했습니다.

## 결론 (Answer First)

**1호점은 삼성·영동대로(봉은사역~코엑스 북문, 영동대로 변 1층 22평)에 여는 커피 주도 그랩앤고 매장입니다.**

| 지표 | 값 |
|---|---|
| 정상 영업 연도(2028) 순매출 | 5.4억 원 (하루 158건 × 건당 9,900원) |
| 2029년 영업이익 | 1.07억 원 (14.9%) |
| 손익분기 거래량 | 하루 144건 (권역 평균 158건보다 9% 낮음) |
| 초기 투자 | 1.82억 원 (4-wall EBITDA 기준 회수 2.3년) |

근거는 세 가지입니다.
1. **서울은 제로섬 시장입니다.** 커피·제과 매출은 연 3.61조 원으로 3년 연평균 +0.2%이고, 점포는 21,888곳에서 20,996곳으로 892곳 줄었습니다.
2. **매장이 이익을 내는 곳은 삼성뿐입니다.** 점포당 하루 158건으로 서울 평균 60건의 2.6배입니다. 같은 매장 기준으로 감당할 수 있는 임대료가 ㎡당 14.2만 원으로, 테헤란로 1층 시세 7.29만 원의 두 배쯤 됩니다. 영등포는 임대료를 0원으로 잡아도 적자입니다.
3. **삼성에서 커피는 +35%, 빵은 −33%입니다.** 핵심 5개 상권 기준 3년 비교입니다. 그래서 커피가 이끌고 빵은 함께 사 가는 업태로 설계했습니다.

## 분석 방법

- **단위**: 서울시 상권 1,650곳을 중심 상권 반경 1km 권역으로 묶었습니다. 연매출 60억 원 이상, 점포 25곳 이상인 1,105개 권역을 비교했습니다.
- **기간**: 2022년 3분기~2023년 2분기와 2025년 3분기~2026년 2분기를 비교한 3년 연평균입니다. 모멘텀은 최근 1년 비교입니다.
- **점수**
  - 실현 성장 40%: 커피 매출 CAGR, 거래건수 CAGR, 모멘텀
  - 선행 수요 40%: 직장·상주·유동 인구의 증가율과 증가 인원
  - 공급 여백 20%: 매출 증가율과 점포 증가율의 차이, 점포당 매출
- **데이터 왜곡 제거**: 집계 범위가 바뀐 상권(예: 마곡역은 2025년 2분기 전 매출 0원)과 한 분기에 60% 넘게 뛴 상권(예: 잠실역 제과 63억→289억 원)은 매출 성장 계산에서 뺐습니다.

## 폴더 구조

```
analysis/   데이터 수집·가공·점수화·손익 모델 (Python 3, 표준 라이브러리)
  dl.py         서울 열린데이터광장 OpenAPI 수집 → raw/ (커밋하지 않음)
  build.py      상권 단위 마스터 테이블(master.json), 좌표 변환(EPSG:5181→WGS84)
  robust.py     데이터 왜곡을 걸러 낸 1km 권역 성장 점수 (최종 모델)
  score.py, cluster.py   초기 점수 모델 (비교용)
  areas*.py, final.py, cmp3.py   후보 권역·입지 상세, 보고서 데이터
  pnl.py        1호점 손익 시뮬레이션 (보수·기준·낙관, 민감도)
  output/       보고서에 쓴 가공 결과 (JSON)
reports/    클라이언트용 HTML 보고서 2종
video/      2분 피칭 영상과 생성 코드 (Pillow + NumPy + ffmpeg, edge-tts)
```

## 출처와 한계

- **상권 데이터**: 서울 열린데이터광장 상권분석서비스 OpenAPI입니다(추정매출, 길단위인구, 직장인구, 상주인구, 점포, 상권변화지표, 상권영역, 집객시설). 2026년 11월 14일에 조회했습니다.
- **임대료**: 한국부동산원 상업용부동산 임대동향(전국 중대형 상가 ㎡당 26,700원, 1층 기준)과 테헤란로 상권 ㎡당 72,900원을 썼습니다. 테헤란로 값은 부동산원 집계를 인용한 2차 자료입니다.
- **인건비 등 비용**: 2027년 최저임금 시급 10,700원을 기준으로 했습니다. 외식업체 경영실태조사(농림축산식품부·한국농촌경제연구원)를 원가 구조의 참고치로 썼습니다.
- **추정매출의 성격**: 카드 결제 기반 추정치이고 부가세가 포함되어 있습니다. 손익 계산에서는 1.1로 나눠 순매출로 바꿨습니다.
- **개발 일정**: GTX-A 삼성역과 영동대로 복합환승센터(2028년 목표) 같은 일정은 데이터가 아니라 공개 계획을 기준으로 했습니다. 출점 결정 전에 다시 확인해야 합니다.
- **음성**: 내레이션은 Microsoft 뉴럴 음성(edge-tts)이고, 배경음은 코드로 합성했습니다.
